# 微光习惯

一个使用 React、TypeScript 和 Vite 构建的单页习惯打卡应用。支持每日打卡、今日完成数、历史补记、按习惯统计连续天数，以及本地数据持久化。

## 本地运行

直接双击 `index.html` 即可在浏览器中使用，不需要安装任何依赖。记录保存在当前浏览器中。

如果需要使用 React 开发版本：

```bash
npm install
npm run dev:react
```

浏览器打开终端中显示的本地地址即可。所有记录保存在当前浏览器的 `localStorage` 中，不会上传到服务器。

## 检查

```bash
npm test
npm run build
```

## 使用说明

- 在“今日习惯”中添加想坚持的习惯，点击右侧圆框完成打卡。
- 月历中可选择过去的日期补记；未来日期不可操作。
- 删除习惯会将它从每日清单归档，保留历史并支持 5 秒内撤销。
- 连续天数按每个习惯独立计算；当天尚未打卡时，从昨天开始统计，避免提前断签。

## 发布到手机访问

`index.html`、`src/styles.css` 和 `src/local-app.js` 是完整的静态站点，可以原样上传到 GitHub Pages、Netlify、Cloudflare Pages 或任意静态网站托管服务。部署后获得一个 `https://` 开头的网址，用手机浏览器打开即可。

打卡数据保存在每台设备自己的浏览器中，因此手机和电脑的数据不会自动同步。
